# Changelog

## Version 4 (October 17, 2026)

Copied from the latest Claude artifact (coral-v159).

New in this version:
- **Her view** is picture-first: picture cards with no clock times, a First → Then board with a visual timer ring, a token board for what she's working for, and her own break button.
- **Teacher view** adds a Now / Next bar, the goal and materials for each block, an arrival check-in, and three quick "yes" warm-ups before each learning block.
- **Behavior notes:** ABC notes ("What happened right before?") after Spit, Hit, Refused, Left or Frustration, plus break asks, in each block's behavior row.
- **Shelly** gives mid-session nudges, an end-of-session wrap-up and a weekly note for Mom. The notes need Claude, so on GitHub Pages they say they aren't available.
- **IEP Tutoring Progress Log:** one question at a time, then a filled-in copy of the paper form to print.
- **Month calendar:** tap a date to open it. Earlier days' notes are inside it.
- **Family view:** people who can only view the shared Claude page see just the recap.
- **Privacy and data:** a privacy notice, a parent/guardian consent record, and download or delete all records.
- **More worksheets:** new sets alongside Word Family, At the Place and Reading Comprehension.
- Polish: a gentle current line ahead of the dive anchor, and a slower sun/moon rise you can tap to skip.

Changes to the GitHub Pages copy:
- Files now sit in folders (`aslgif/`, `asl/`, `ws/`, `pdfjs/`), matching the Claude version. The old loose files and `asl-media.js` were removed.
- `standalone.js` replaces the old built-in offline code. Anything already saved in a browser carries over.
