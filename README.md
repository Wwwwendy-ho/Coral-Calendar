# Alissa's Move & Learn Plan (Tide Chart)

A stand-alone copy of the plan for GitHub Pages.

## Put it online
1. On github.com, create a new repository (for example `alissa-tide-chart`).
2. Choose **Add file → Upload files**, drag in everything inside this folder (`index.html`, `README.md`, `.nojekyll`, and the `ws` and `pdfjs` folders), then **Commit changes**.
   - `.nojekyll` is a hidden file; if your computer hides it, it's fine to skip it.
3. Open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main** and folder **/ (root)**, then **Save**.
4. After a minute or two the page is live at `https://YOUR-USERNAME.github.io/alissa-tide-chart/`.

## What's different from the Claude version
- Plan edits, moved lessons and switched games are saved **in the browser you use**, not shared between devices or people.
- PDFs open in a preview first. **Open to print** opens the PDF in a new tab so you can print it; **Save PDF to print** downloads it.
- Everything else (calendar, High/Low Tide, timer with wave sound, worksheets, cards, game library) works the same.

## Privacy
On a free GitHub account, Pages sites are public. The worksheets in `ws/` include Alissa's name, so anyone with the link could see them.
